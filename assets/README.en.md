Stores reusable static resources and templates needed while creating or using
Skills.

Current contents:

- `evals-template.json`: Template for evaluation files in new Skills.

Files in this directory should be reusable across workflows or consistently
constrain an output format. Put operating instructions in `SKILL.md` or
`references/`, not in `assets/`.
